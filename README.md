❤️ Heart Disease Prediction

A Machine Learning project that predicts whether a person is likely to have heart disease based on medical and clinical features.

📌 Project Overview

Heart disease is one of the major health concerns worldwide. The objective of this project is to build a Machine Learning classification model that can analyze patient-related features and predict the likelihood of heart disease.

The project was developed using Python and Jupyter Notebook and includes data preprocessing, exploratory data analysis, model training, and model evaluation.

🎯 Objectives
Analyze the heart disease dataset.
Perform data preprocessing and cleaning.
Explore relationships between medical features.
Train a Machine Learning classification model.
Evaluate model performance using appropriate metrics.
Predict the presence or absence of heart disease.

📊 Dataset

The project uses a heart disease dataset containing patient-related medical attributes.

The dataset includes features such as:

Age
Sex
Chest pain type
Resting blood pressure
Cholesterol
Fasting blood sugar
Resting ECG
Maximum heart rate
Exercise-induced angina
Oldpeak
Other clinical features

The target variable represents whether heart disease is present.
